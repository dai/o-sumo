# 大相撲データ（o-sumo）利用ルール

このプラグインが有効化されている間、大相撲や力士に関する質問に応答する際は以下のガイドラインに従ってください。

## 検索とデータ取得の手順
- 力士名（四股名や読み）で質問された場合は、推測で回答せずまず `search_rikishi` ツールで力士を検索して `id` を特定してください。
- 特定した `id` を用いて `get_rikishi_profile` を呼び出し、正確な身長・体重・出身地・初土俵・通算成績（勝敗分）を取得して回答に反映してください。
- 場所の番付や勝星・星取表については `get_banzuke` を使用してください。指定がない場合は最新場所、過去の場所は `YYYYMM`（例: `202609`）を指定します。
- 日別の取組結果や対戦日程については `get_torikumi` を使用してください（日付フォーマット: `YYYYMMDD`）。
- 開催場所の一覧や現在有効な場所キーを確認したい場合は `list_basho` を参照してください。

## 表示形式の指針
- 日本の伝統的な大相撲表記（東・西、横綱・大関・関脇・小結・前頭・十両）に沿って見やすく整理して提示してください。
- 星取表や勝敗は「〇勝●敗」や表形式で簡潔かつ分かりやすくまとめてください。
