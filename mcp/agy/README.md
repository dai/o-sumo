# o-sumo for Google Antigravity

[日本語](#日本語) · [English](#english)

## 日本語

1. [Antigravity用ZIP](https://osada.us/agents/o-sumo-plugin.zip)をダウンロードして展開します。
2. Antigravity CLIで、展開した `o-sumo` フォルダーの親ディレクトリから `agy plugin install ./o-sumo` を実行します。Antigravityアプリで手動導入する場合は、`plugin.json` が入った `o-sumo` フォルダーを `~/.gemini/config/plugins/` に置きます。
3. プラグイン一覧または `agy plugin list` で有効になっていることを確認し、チャットで「o-sumoで2026年9月27日の取組結果を調べて」と聞きます。

[プラグインのソース](./o-sumo/) · [Antigravity公式の導入手順](https://antigravity.google/docs/plugins#manual-plugin-installation) · [ほかのクライアント](../README.md#日本語)

## English

1. Download and extract the [Antigravity ZIP](https://osada.us/agents/o-sumo-plugin.zip).
2. Run `agy plugin install ./o-sumo` from the parent of the extracted folder. For manual installation in the Antigravity app, place the `o-sumo` folder containing `plugin.json` in `~/.gemini/config/plugins/`.
3. Check that the plugin is enabled in the plugin list or with `agy plugin list`. In chat, ask “Use o-sumo to look up the bout results for September 27, 2026.”

[Plugin source](./o-sumo/) · [Antigravity installation docs](https://antigravity.google/docs/plugins#manual-plugin-installation) · [Other clients](../README.md#english)
