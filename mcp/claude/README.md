# o-sumo for Claude

[日本語](#日本語) · [English](#english)

## 日本語

1. Claudeの「Customize」→「Connectors」でカスタムコネクターを追加します。
2. 名前を `o-sumo`、リモートMCPのURLを `https://osada.us/mcp` に設定します。認証は「No sign in」を選びます。
3. チャットでコネクターを有効にし、「o-sumoで大の里のプロフィールを調べて」と聞きます。

追加できるユーザーはプランとワークスペースの権限によって異なります。Claude Desktopでもリモート接続はこの手順で設定します。[Claude公式の手順](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp) · [ほかのクライアント](../README.md#日本語)

## English

1. In Claude, go to **Customize → Connectors** and add a custom connector.
2. Name it `o-sumo` and enter `https://osada.us/mcp` as the remote MCP URL. Choose **No sign in** for authentication.
3. Enable the connector in chat and ask “Use o-sumo to look up Onosato (大の里).”

Availability depends on your plan and workspace permissions. Use the same remote connector setup for Claude Desktop. [Claude setup instructions](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp) · [Other clients](../README.md#english)
