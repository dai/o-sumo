# o-sumo for Grok

[日本語](#日本語) · [English](#english)

## 日本語

1. [GrokのConnectors](https://grok.com/connectors)で「New Connector」→「Custom」を選びます。
2. 名前を `o-sumo`、URLを `https://osada.us/mcp` に設定します。o-sumo側の認証情報は不要です。
3. チャットでコネクターを選び、「o-sumoで2026年9月場所の番付を調べて」と聞きます。

Business・Enterpriseでは、管理者がコネクターを設定します。[Grok公式の接続手順](https://docs.x.ai/grok/connectors) · [ほかのクライアント](../README.md#日本語)

## English

1. Open [Grok Connectors](https://grok.com/connectors) and choose **New Connector → Custom**.
2. Set the name to `o-sumo` and the URL to `https://osada.us/mcp`. o-sumo requires no credentials.
3. Select the connector in chat and ask “Use o-sumo to look up the September 2026 banzuke.”

For Business and Enterprise accounts, an admin configures the connector. [Grok setup instructions](https://docs.x.ai/grok/connectors) · [Other clients](../README.md#english)
