## 日本語

[`muse_connector.json`](./muse_connector.json) は、o-sumoの公開MCP `https://osada.us/mcp` を使う開発・提出用の設定例です。Museで利用者向けに配布するには、Metaの要件に沿って設定・提出し、審査を受けます。o-sumoのディレクトリ掲載は未確認です。

[Metaのコネクターガイドライン](https://platform.muse.ai/docs) · [ほかのクライアント](../README.md#日本語)

## English

[`muse_connector.json`](./muse_connector.json) is a development and submission example for the public o-sumo MCP at `https://osada.us/mcp`. To distribute a connector through Muse, follow Meta's setup and submission requirements and complete its review. An o-sumo directory listing has yet to be verified.

[Meta connector guidelines](https://platform.muse.ai/docs) · [Other clients](../README.md#english)
