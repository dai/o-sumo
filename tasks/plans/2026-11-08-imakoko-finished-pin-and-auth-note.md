# 追加修正指示（2026-11-08 夜、Osada 指示）

## 1. 終了後のピンをその日いっぱい右端に

要望: 当日の取組が終わったあと、**18:01〜23:59（JST）はピンがバーの右端にいる**状態にしてほしい。

現状（2026-11-08 20:48 JST に本番で目視確認）:
- カードのステータスは「本日の取組は終了しました」、バーは全域金色（100%）で正しい。
- しかし ▲ ピンは右端ではなく、バーの約75〜80%の位置（幕内ゾーン右寄り）に見える。

対応:
- `finished` 状態ではピンがバーの右端（100%）に視覚的に一致するよう、ピンアンカー／ラベルの配置を調整する（左端クランプの鏡像として、右端でもピン自体がバーの端に合うように）。
- あわせて、当日の取組終了後は JST の日付が変わるまで（23:59 まで）当日の `finished` 表示を維持し、翌日分の「取組前」に切り替わらないことを確認する（データ選択 `resolveLiveDailyData` 側で翌日に先行しないこと）。
- 難易度メモ: 状態判定は既存の `finished` を使うため、追加は表示位置の調整と日付境界の確認が中心。

テスト観点:
- 全番終了データ＋20:00 の時刻で、ピンが右端（100%）・バー満杯・「本日の取組は終了しました」。
- 同データ＋23:59 でも同じ。00:00 以降は翌日の「取組前」・ピン左端に切り替わること。

## 2. スマホで認証まわりの注記テキストが途切れる

現象: スマホ表示・Google 非ログイン時に、「パスワードは不要です」系の注記（locale の `storageNote` / `passwordHint` 等、My Rikishi のログイン説明ブロック）の位置が途切れて見える。

要望（Osada）: **ブロック内では何行になってもいいので、テキストはブロック内に収める**。

対応:
- 該当要素のレイアウトを見直し、モバイル幅でもテキストがコンテナからはみ出さない・途切れないようにする（`nowrap` の解除、固定高さや絶対配置によるクリッピングの解消、必要なら折り返し前提の余白確保）。
- デスクトップ表示の見た目は変えない。

テスト観点:
- モバイル幅（例: 390px）・未ログイン状態で注記がブロック内に全文表示されること（スクリーンショットで確認）。
