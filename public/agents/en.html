Agent access

Public banzuke, torikumi, and rikishi data are available through read-only JSON APIs and MCP. The public APIs, sumo data MCP, and Agent Skills require no account or API key.

Public JSON APIs

Retrieve torikumi data directly, or see the API reference for all endpoints.

Machine-readable catalog: https://osada.us/.well-known/api-catalog

Sumo data MCP

Five tools cover rankings, bouts, rikishi search, profiles, and basho listings. Configure https://osada.us/mcp in an MCP client. This is a Streamable HTTP endpoint, not a browser page.

View the Server Card

AI Search MCP

The search tool supports natural-language searches of articles and profiles. Configure https://ask.osada.us/mcp in an MCP client. Browser GET requests are not supported.

Agent Skills and WebMCP

See the published skill descriptions for data and URL guidance. Supported browsers separately register four WebMCP tools when the site opens.

Machine-readable index: https://osada.us/.well-known/agent-skills/index.json

Usage and documentation

Search and query-time answers are permitted; model training is not. See the agent guide and authentication policy. The A2A card is for discovery only; task operations are not implemented.
