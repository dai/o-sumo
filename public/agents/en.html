Look up grand sumo data with AI

Use the sumo data MCP for banzuke, bouts, and rikishi. Use AI Search MCP to find articles and profiles, or the public JSON API to fetch data in code.

Connect to the sumo data MCP

Add https://osada.us/mcp to a client that supports remote MCP. The transport is Streamable HTTP. The server is read-only and requires no o-sumo sign-in or API key.

Setup by client · Server Card

Try these requests in chat

  • Use o-sumo to look up Onosato (大の里) and his career record.
  • Use o-sumo to look up the makuuchi banzuke for September 2026.
  • Use o-sumo to look up the makuuchi bout results for September 27, 2026.

For bouts, give a date and ask for the schedule or the results. Unpublished bouts can appear as pending. Dates outside the available data return no data.

Find articles with AI Search MCP

Add https://ask.osada.us/mcp to find candidate articles and profiles with the search tool. Open the sources it returns and verify rankings and results with the sumo data MCP.

Usage and privacy

Search and use as a source when answering questions are allowed. Model training and fine-tuning are prohibited. The A2A card is for discovery.
