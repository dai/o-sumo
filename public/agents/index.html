AIエージェント向け案内

番付、取組、力士などの公開データを、JSON APIやMCPから読み取り専用で利用できます。公開JSON API、相撲データ用MCP、Agent Skillsに登録やAPIキーは不要です。

公開JSON API

取組データなどを直接取得できます。APIの一覧と仕様はAPI仕様を参照してください。

機械向けの一覧: https://osada.us/.well-known/api-catalog

相撲データ用MCP

番付、取組、力士検索、プロフィール、場所一覧を取得する5つのツールを提供します。MCPクライアントに https://osada.us/mcp を登録してください。このURLはブラウザーで開くためのページではなく、Streamable HTTPの接続先です。

Server Cardを見る

AI Search MCP

記事やプロフィールなどを自然言語で探す search ツールです。MCPクライアントに https://ask.osada.us/mcp を登録してください。ブラウザーからのGETは利用できません。

Agent SkillsとWebMCP

データ取得とページURLの解決方法は公開スキルの説明を参照してください。対応ブラウザーでは、サイトを開くと別途4つのWebMCPツールを登録します。

機械向けの一覧: https://osada.us/.well-known/agent-skills/index.json

利用条件と詳しい説明

検索と回答生成時の参照は許可し、モデル学習は許可しません。エージェント向けガイドと認証方針を参照してください。A2Aカードは発見用で、タスク操作は未実装です。
